# X millenium for Brain
電子辞書Brainでちゃんとキー入力できるようにしたX1エミュレータのX millenniumです。
YUI氏作成のソースコードをもとに改変したものなので著作権はYUI氏にあります。
またローマ字入力機能についてはQuasi88のソースコードを一部使用しています。

修正しているのは、以下の5つの追加機能です。

## 追加機能
### (1)Brain用キー割り当て
キーボードは以下のようなマッピングになっています。(第3世代のキーボード)

#### 通常時
<pre>
  Q W E R T Y U I O P
   A S D F G H J K L
SFT Z X C V B N M - BS
   切替 ESC SPC  ←↑→
   記号            ↓
</pre>

### (3)ローマ字入力
