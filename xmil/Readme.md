# X millenium for Brain
電子辞書Brainでちゃんとキー入力できるようにしたX1エミュレータのX millenniumです。
YUI氏作成のソースコードをもとに改変したものなので著作権はYUI氏にあります。
またローマ字入力機能についてはQuasi88のソースコードを一部使用しています。

修正しているのは、以下の5つの追加機能です。

## 追加機能
### (1)Brain用キー割り当て
キーボードは以下のようなマッピングになっています。(第3世代のキーボード)

[切替]キーを押すと、2段目のように一部が数字もしくは記号の配列に置き換わります。この状態で[SFT]キーを押すと、3段目のように各種記号が入力できます。
なお、[戻る]キーは[Esc]キーに、[履歴/しおり]キーは[F5]にマッピングされています。

#### 通常時
<pre>
[電源] [F1][F2][F3][F4][F5][  ][  ][  ]
  [Q] [W] [E] [R] [T] [Y] [U] [I] [O] [P]
    [A] [S] [D] [F] [G] [H] [J] [K] [L]
[SFT] [Z] [X] [C] [V] [B] [N] [M] [-] [BS]
   [切替] [ESC] [SPC] [ENTER] [←][↑][→]
   [カナ]                        [↓]
</pre>

#### 切替キーを押したとき
<pre>
[電源] [F1][F2][F3][F4][F5][  ][  ][  ]
  [1] [2] [3] [4] [5] [6] [7] [8] [9] [0]
    [A] [S] [^] [\] [@] [[] [;] [:] []]
[SFT] [Z] [X] [C] [,] [.] [/] [_] [-] [BS]
   [切替] [ESC] [SPC] [ENTER] [←][↑][→]
   [カナ]                        [↓]
</pre>

#### 切替キーを押した後、シフトキー(SFT)を押したとき
<pre>

[電源] [F1][F2][F3][F4][F5][  ][  ][  ]
  [!] ["] [#] [$] [%] [&] ['] [(] [)] [0]
    [A] [S] [~] [|] [`] [{] [+] [*] [}]
[SFT] [Z] [X] [C] [<] [>] [?] [_] [=] [BS]
   [切替] [ESC] [SPC] [ENTER] [←][↑][→]
   [カナ]                        [↓]
</pre>

また、[カナ]キーを押すとかな入力モードになります。ローマ字入力モードがONの場合は、あわせてこの状態で[切替]キーを押すと2段目のように赤文字部分の配列が置き換わります。
