# X millennium for Brain
電子辞書Brainで数字などが入力できるようにX millenniumを改変したX1エミュレータです。
YUI氏作成のソースコードをもとに改変したものであるため、著作権はYUI氏にあります。

また、ローマ字入力機能についてはQuasi88のソースコードを一部使用しています。

オリジナルの X millennium に対し、以下の5つの機能を追加・修正しています。

## 追加機能
### (1)Brain用キー割り当て
キーボードは以下のようなマッピングになっています。(第3世代のキーボードを例に示します。)

[文字切替]キー(以降は[切替]キーと表記)を押すと、一部が数字もしくは記号の配列に置き換わります。この状態で[SFT]キーを押すと、各種記号が入力できます。
なお、Brain用の特殊キーは以下の通りにマッピングされます。

|[英和/和英]|[F3]|
|[My辞書]|[F4]|
|[履歴/しおり]|[F5]|
|[マーカーテスト]|[TAB]|
|[ツール]|[CTRL]|
|[HOME]|[CAPS Lock]|

### (2)サウンドミュート
外に持ち出して使う場合は、サウンドをOFFにして使いたいときが多いと思いますが、Brainでのボリューム調整は、辞書メニューから設定まで移動しなければなりません。
このため、エミュレータ内に独自のミュート機能を実装しています。2026/8/18のバージョンより、前回ミュートが有効な状態で終了した場合は、有効な状態で起動します。無効状態で終了した場合は、無効状態で起動します。
サウンドのON/OFFは、メニューから[Emulate]→[Mute]をタップして、ミュートを有効/無効にしてください。

### (3)ローマ字入力
Quasi88のソースコードを元にローマ字入力機能を実装しています。
ローマ字はMS-IME仕様のみサポートしています。
起動時は必ずローマ字入力が有効な状態で起動します。ローマ字入力をOFFにしたい場合は、メニューから[Emulate]→[Romaji input]をタップするとローマ字入力が無効化されカナ入力モードになります。

### (4)どこでもセーブ
簡易的などこでもセーブ&ロード機能を実装しています。
メニューの[Emulate]→[Quick Save]→[Slot n] (nは1～10)を選択すると、現在の状態を`AppMain.exe`が存在するフォルダに`xmilstat.001～010`というファイル名で保存します。
なお、同名ファイルが存在した場合は、上書き確認のダイアログが表示されます。

ロードも同じように[Emulate]→[Quick Load]→[Slot n] (nは1～10)を選択すると`AppMain.exe`が存在するフォルダの`xmilstat.001～010`を読み込んで再開します。

### (5)テープ読込対応
テープの読込に対応しています。（書込は未対応です。）

メニューの[Tape]→[Open]でファイル選択ダイアログが開くので、拡張子 TAPのファイルを選択してください。なお、対応しているファイルはサンプリングレートが8KHzのファイル(Windows版 X millennium t-tuneでサポートされているファイル形式)のみです。

また、テープをセットした状態で、メニューの[Tape]→
- [Stop]でテープ停止ボタンを押す
- [Rew]でテープ巻き戻しボタンを押す
- [Eject]でテープ取り出しボタンを押す

といった操作が可能となります。

## インストール方法
まずは、`AppMain.exe`をダウンロードし、Brainの`アプリ`フォルダ配下に適当なフォルダ名(例えば`XmilBrain`)でフォルダを作成し、そこに配置してください。
あわせて、`Index.din`、`AppMain.cfg`ファイルも配置してください。
BIOSなどのファイルは同じフォルダに配置すればOKです。

あとは、辞書メニューの追加アプリから起動できます。
このあたりの詳細は、[BrainWiki](https://brain.fandom.com/ja/wiki/%E3%82%A2%E3%83%97%E3%83%AA%E3%81%AE%E8%B5%B7%E5%8B%95%E6%96%B9%E6%B3%95)に詳しく記載されていますので、そちらをご参照ください。

なお、`gx.dll`も必要なため、[こちらの記事](https://qiita.com/nekopro2/items/ae1dd0fe8e4ee0bc23ba)などを参考に配置してください。

### ※高解像度モードで起動しない場合
0バイトの`AppMain.cfg`を置いただけでは高解像度モードで起動しない場合があります。
この場合は、PCにて`AppMain.cfg`をバイナリエディタで開き、

```
01 00 00 00 FF FF FF FF
```

と入力して保存し、このファイルに差し替えるようにしてください。
